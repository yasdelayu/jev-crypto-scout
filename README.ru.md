# Jev Crypto Scout

**[English version](README.md)**

Скрининг монет: количественные сигналы считаются в коде на реальных
рыночных данных (CoinGecko, Bybit); качественное суждение о новостях
(тональность / тип катализатора / подтверждённость) — через
[Jev](https://typesafe.ai), модель TypeSafe класса System One. Честный
разбор того, что это умеет и не умеет, включая скальпинг-модуль — в
[ARCHITECTURE.md](ARCHITECTURE.md) (на английском, основной язык доков репо).

**Не торговый бот и не инвестсовет.** Ничего не покупает, не продаёт и
не выдаёт торговый сигнал — печатает таблицу, которую читает человек.

---

## Почему так, а не иначе

Jev не умеет надёжно в математику — это прямо в документации TypeSafe
([jaggedness §2, «Math and Numbers»](https://docs.typesafe.ai/model-jaggedness/jev-1.13)).
Поэтому Jev тут никогда не считает индикаторы. Каждый процент, отношение,
RSI, MACD-гистограмма, z-score фандинга — обычная арифметика в
`indicators.py` / `scout.py` / `scalp.py`, на реальных числах CoinGecko
и Bybit, без единого обращения к модели.

Jev используется только там, где нужна именно естественно-языковая
семантика: тональность новости, тип события, подтверждённость. Один
запрос на новость закрывает три вопроса сразу
([speculative fan-out](https://docs.typesafe.ai/patterns/fan-out)).
Веса ранжирования — в коде (`rank()`), не в модели: их можно менять без
единого нового обращения к Jev
([composite scoring](https://docs.typesafe.ai/patterns/composite-scoring)).

## Что в репозитории

| Файл | Что |
|---|---|
| `scout.py` | Топ-N монет по капитализации: моментум, дистанция от ATH, vol/mcap, возраст монеты, осцилляторы, новости через Jev |
| `scalp.py` | Короткогоризонтный **сканер сигналов** (не исполнитель) — экстремальность фандинга + минутные осцилляторы на Bybit, Jev — вето по новостному риску |
| `indicators.py` | RSI / MACD-гистограмма / %B Боллинджера / Stochastic %K — чистый Python, без TA-Lib |
| `colors.py` | ANSI-цвета терминала, сами выключаются вне TTY — без зависимостей |
| `jev_client.py` | Один клиент на три провайдера Jev (нативный TypeSafe / Vercel AI Gateway / Cloudflare Workers AI) |

## Запуск

```bash
python3 scout.py --top 30                          # только количественный скрининг, без Jev
python3 scout.py --coins bitcoin,pepe,fartcoin      # свой список вместо топа по капе
python3 scout.py --top 30 --age --ta                # + возраст монет + осцилляторы
python3 scout.py --top 30 --fng                     # + Fear&Greed Index, DeFi TVL (фон рынка)
python3 scout.py --top 30 --scalp                   # + сканер фандинга/1м-осцилляторов Bybit на тех же монетах
python3 scout.py --top 30 --news                    # + классификация новостей через Jev (нужен ключ)

python3 scalp.py --symbols BTCUSDT,ETHUSDT,SOLUSDT          # фандинг + минутные осцилляторы, отдельно
python3 scalp.py --symbols BTCUSDT --news                    # + вето Jev по новостям

python3 scout.py --selftest && python3 scalp.py --selftest && python3 indicators.py
```

Цветной вывод в терминале (зелёный/красный по знаку, жёлтый для тегов Jev)
включается сам на настоящем терминале и выключается сам при выводе в файл —
см. `colors.py`, без зависимости от `rich`/`colorama`.

Ключ Jev — любой из трёх:

```bash
export AI_GATEWAY_API_KEY=vck_...                                   # Vercel
export TYPESAFE_API_KEY=...                                          # нативный
export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=...            # Cloudflare
```

Без ключа `--news` завершается понятной ошибкой, не трейсбэком.
`JEV_PROVIDER=demo` гоняет весь конвейер на открытой модели-заменителе
(не настоящий Jev, но проверяет всю проводку без единого ключа).

## Что такое scalp-модуль на самом деле

Два независимых сигнала, оба — чистая арифметика, оба с публичного v5
API Bybit (без ключа для рыночных данных):

- **экстремальность фандинга** — на сколько стандартных отклонений
  сегодняшний фандинг перпа отклоняется от собственной недавней истории.
  Устойчиво высокий положительный фандинг значит, что лонги перегружены
  и платят шортам.
- **минутные осцилляторы** — те же формулы RSI/Stochastic, что и в
  `--ta`, только на гораздо более коротком таймфрейме.

Кандидатом становится только тот случай, где **оба** сигнала указывают
в одну сторону одновременно — любой один сам по себе это шум. Jev
включается ровно один раз на выжившего кандидата, как **вето**, не
предсказатель: есть ли очень свежая, уверенная, медвежья/регуляторная
новость по этому символу? Если да — кандидат гасится: экстремальный
фандинг или RSI ничего не значат, если реальная причина — взлом или
регуляторное действие, которого осциллятор в принципе не видит.

Это скрининг-подсказка на цикле опроса в масштабе минут, не система
живого исполнения. Что на самом деле нужно для настоящей
скальпинг-инфраструктуры и почему этот репозиторий сознательно
останавливается раньше — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Источники данных

- [CoinGecko](https://coingecko.com) — рыночные данные, OHLC, без ключа
- [Bybit v5](https://bybit-exchange.github.io/docs/v5/intro) — фандинг, минутные свечи, без ключа для рыночных данных. Выбран вместо Binance, который отдал `451 Unavailable For Legal Reasons` с части нашей тестовой инфраструктуры (гео-блок биржи)
- [Cointelegraph RSS](https://cointelegraph.com/rss) — источник новостей для разбора через Jev
- [CoinMarketCap](https://coinmarketcap.com/api/) — опциональный запасной источник рыночных данных. `listings/latest` работает **без ключа** (проверено вживую), `quotes/latest` — нет (403 без ключа). См. `cmc.py`
- [Alternative.me Fear & Greed Index](https://alternative.me/crypto/fear-and-greed-index/) — общее настроение рынка, флаг `--fng`, без ключа
- [DeFiLlama](https://defillama.com/docs/api) — суммарный TVL DeFi по всем сетям, флаг `--fng`, без ключа

## Ограничения

- Один RSS-фид по умолчанию — добавляй свои в `NEWS_FEEDS` в `scout.py`.
- Сопоставление «новость ↔ монета» — подстрочный фильтр в коде, не Jev:
  дёшево и быстро, но пропускает непрямые упоминания.
- `--age` и `--ta` упираются в rate limit free-тира CoinGecko на большом
  `--top`; прочерк в таблице значит заблокированный запрос, не «нет данных».
- Калибровка Jev на финансовом английском и на русском здесь не
  верифицирована на большой выборке — см. более общий разбор технологии
  и замерялку калибровки в
  [typesafe-ai/skills](https://github.com/typesafe-ai/skills).
